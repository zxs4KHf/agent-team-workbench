# 每日工作台

本插件为独立的个人助理工作台提供协作台导航入口。服务、每日主线、任务资料和本人审阅记录由个人助理项目的 `workbench/` 维护；插件只通过 HTTP 发现服务并嵌入页面，不复制团队会话或资料，不导入个人助理代码。

## 使用

1. 启动个人助理的每日工作台 HTTP 服务，默认端口 8790。服务的团队地址应指向本机 Agent 协作台。
2. 在协作台「扩展与来源 → 插件」启用「每日工作台」，核对端口。默认项目 slug 留空，按任务选择；也可以在插件配置中指定默认项目。
3. 从插件入口打开每日工作台，或使用「独立打开」。服务离线时页面显示重新连接与插件配置入口。

启用本插件不会启动个人助理服务或 Agent。停用插件后，代理接口不再可用；已有资料和任务继续保留在所属服务中。

## 服务发现契约

`GET /api/daily-workbench/plugin-info` 由协作台代理到配置的本机端口，原路径保持不变。就绪响应：

```json
{
  "id": "daily-workbench",
  "ready": true,
  "url": "http://127.0.0.1:8790/?embedded=1",
  "team_url": "http://127.0.0.1:8765"
}
```

页面要求 `id` 精确匹配、`ready` 为布尔值 `true`。两个 URL 只接受 HTTP、明确的本机地址（`127.0.0.1`、`localhost` 或 `[::1]`）、1024–65535 端口和根路径，不接受凭据或片段。嵌入地址的查询串必须为 `?embedded=1`，团队地址不能有查询串。独立打开地址从已校验的嵌入地址派生。

团队任务的派发与成果回传由个人助理服务对接协作台的通用 `/api/plugin-jobs`、`/api/task` 接口；此插件页面只读取服务发现信息。
