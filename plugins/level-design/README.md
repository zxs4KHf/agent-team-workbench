# Level Design Workbench

关卡工作台以独立本机服务维护资料、批注、设计任务和本人验收。本插件提供协作台导航入口与服务发现，使用 `/api/plugin-jobs` 将资料任务提交到所选项目的团队队列。

## 使用

1. 启动关卡项目自己的 `workbench/pipeline/workbench_server.py`，默认端口 8766。使用其他协作台端口时，传入 `--team-url http://127.0.0.1:<端口>`。
2. 在协作台「扩展与来源 → 插件」启用 Level Design Workbench。配置关卡服务端口与默认项目 slug，私人目录留在来源项目。
3. 从插件页面打开关卡任务，选择「提交到团队队列」，确认所属项目、团队与模式。默认使用抢单，一位成员领取后撤回其他副本；也可以选择讨论、独立作答、红队或接力，并限定团队内的参与成员。
4. Agent 按任务包调用 `bus_reply`，关卡服务读取成果。任务进入「待本人参与」，本人反馈与验收继续在关卡工作台完成。

插件使用现有关卡服务，启用面板不会启动 Agent 或新增模型调用。关闭插件会隐藏入口并停止接受新的插件派发；已经投递的任务和成果保留在各自工作台中。

提交后即生成协作台项目任务，进入成员的现有收件队列。静态团队成员离线时保持排队，执行期限从领取时计算。任务详情显示团队、模式、领取者和协作台任务链接。尚无人领取时可以取消本次安排，关卡事项和资料继续保留。

## 接口

- `/api/level-design/plugin-info`：代理到配置端口，读取关卡页面地址。
- `/api/plugin-jobs/options?source=level-design`：读取项目、团队、资料协作模式与成员状态。
- `/api/plugin-jobs`：按来源和请求编号幂等入队或查询，保存项目、团队、模式与提交时的成员范围。
- `/api/plugin-jobs/cancel`：取消尚无人领取的安排，与领取使用同一任务锁。
- `/api/task?id=…`：读取所关联任务的进度和回复。

任务带有外部来源标记，自动合并、自动改派和普通任务自动收尾跳过这些任务。等待、HTTP 同步和页面刷新由程序处理；MCP 待命调用超时后，客户端再次调用工具仍可能产生模型开销。

材料仅包含任务关联来源及已有转录、关键帧位置。任务要求按需读取、返回证据、保留无法核实内容；读取失败不会推断分析完成，也不会代替本人填写感想。
