# 0011 前端重构：统一设计语言 + 把动效接进状态变化

- 状态：已采纳（用户 2026-10-01 批准）。阶段 0 已完成（feat/design-ratchet-20261001），下一步阶段 1
- 范围：`web/v2/`（工作台主界面、hub、arena 页、体验反馈浮层）。后端不动。

## 情况（用数说话，2026-10-01 在 main@1026df0 扫描）

用户的两条目标：**有动感**（界面跟着状态动起来，而不是整块刷新）、**设计语言统一**（每一页看起来是同一套东西）。底子其实已经在：

| 已有的 | 在哪 |
|---|---|
| 颜色 / 字号 / 间距 / 圆角 / 阴影 / 动效时长与缓动的变量，5 套主题，对比度有测试守着 | `styles/tokens.css`、ADR 0007 |
| 局部更新（idiomorph，保留焦点和滚动） | `core.js morph()` |
| 列表重排动画、数字滚动、视图过渡 | `core.js flip()` / `animateNumber()` / `viewTransition()` |

但页面基本没在用它们，而是各写各的：

| 指标 | 现在 | 说明 |
|---|---|---|
| JS 模板里的内联 `style="…"` | **328** | arena.js 105、app.js 83、views2.js 68、views.js 51：样式绕过了设计变量 |
| 不同的 `font-size` 写法 | **102** 种 | 大量 `calc(11px * var(--fs-scale,1))`，而字号阶梯里根本没有 11px |
| 按钮 class 组合 | **61** 种 | `small ghost` / `ghost small` 并存，没有按钮组件 |
| 圆角取值 | 14 种 | 变量之外还有 4/5/6/7/8/9/10px |
| 写死的颜色 | 52 处 hex + 9 处 rgb | 其中 22 处在 `feedback.js`（浮层自带一套配色，换主题不跟） |
| 直接 `innerHTML =` | 43 处 | 这些地方整块替换：没有过渡、会闪、丢滚动位置 |
| `flip()` / `animateNumber()` / `viewTransition()` 的调用 | 1 / 2 / 2 | 动效工具基本闲置 |
| `app.js` | 151 KB / 1175 行 | AGENTS.md 已要求不再往里堆 |

结论：问题不是缺工具或缺配色，而是**没有组件这一层**，每页手写样式；**动效没有接到"状态变化"上**，只在少数地方手动调用。

## 决定

不换框架（继续原生 ES 模块 + idiomorph），不改配色。分 5 个阶段，每阶段可单独合入、单独回滚。

### 阶段 0 · 护栏（先做，最小）

新增 `tests/smoke_design_ratchet.mjs`：统计上表 6 个指标，写进 `tests/design_ratchet.json` 作为上限。**数只能降不能升**：新代码再写内联样式或写死颜色，测试直接失败；每次重构后把上限改低。这样统一是被测试守住的，而不是靠自觉。

> 已落地（2026-10-01）：护栏只数「静态可判定」的写法（含 `${…}` 的动态 class / 字号不计），所以基线与上表粗扫不同，以 json 为准：内联样式 347、写死颜色 41、字号写法 15 种、按钮组合 37 种、`innerHTML =` 44、非变量圆角 57。计数器本身有自测，正则失效会直接报错而不是静默变 0。

### 阶段 1 · 设计语言（tokens + 组件）

1. 字号阶梯补 `--fs-00`（11px），所有 `calc(Npx * var(--fs-scale))` 换成变量；阶梯外的值归到最近一档。
2. 圆角只留 4 个：`--r-ctl` `--r-card` `--r-sheet` `--r-pill`（新增，替代 999px / 50%）。
3. 状态语义一张表：同一个状态（在线 / 空闲 / 思考中 / 施工中 / 待审 / 已合并 / 卡住 / 离线）在所有页面用**同一个颜色 + 同一个图标 + 同一个动效**，写成 `data-state="…"` + CSS，页面只设属性不写颜色。
4. 组件（CSS 类 + `components.js` 里的模板函数，页面只调函数）：
   `btn(label, {kind: primary|ghost|danger|link, size: s|m, icon})`、`chip` / `badge`、`card`、`statusDot`、`avatar`、`toast`、`drawer`、`empty`（空状态）。按钮从 61 种组合收敛到「4 种 kind × 2 种 size」。
5. `feedback.js` 浮层改用 tokens，跟随主题。

### 阶段 2 · 动效层（接进状态变化，一处接线全站生效）

动效词汇只有 5 个，全部只动 `transform` / `opacity`，时长取 `--m-*`，`prefers-reduced-motion` 下归零（tokens 已支持）：

| 名字 | 触发 | 表现 |
|---|---|---|
| enter | 列表里新出现的条目（新任务、新决策、Agent 上线） | 上移 8px + 淡入，`--ease-emph` |
| exit | 条目被移除 | 淡出 + 高度收起 |
| reorder | 条目换位置（排序、置顶） | FLIP，`--ease-spring` |
| state | `data-state` 变化（离线→在线、施工→待审） | 颜色过渡 + 状态点一次脉冲 |
| count | 数字变化（行动条计数、队列长度） | `animateNumber` 滚动 |

接线位置是 `core.js morph()` 的 idiomorph 回调：`beforeNodeAdded` / `beforeNodeRemoved` / `afterNodeMorphed`。列表条目带 `data-key`，数字带 `data-num`，状态带 `data-state`，**页面代码不用调任何动画函数**，改了状态就会动。另外两处"活着"的感觉：

- 思考中 / 施工中的 Agent：卡片上一条细的流光进度条（纯 CSS），一眼看出谁在干活、谁闲着——这也直接服务"Agent 利用率"那几条反馈；
- 页面切换：`viewTransition()` 加命名过渡，Agent 卡片点开详情抽屉时卡片"展开"成抽屉，而不是凭空弹出。

### 阶段 3 · 拆 app.js、去掉整块替换

1. 第一步纯机械搬家（不改逻辑，单独一个提交便于审查）：每个视图一个文件 `web/v2/js/views/<名字>.js`，`app.js` 只留路由、store 订阅和全局动作。
2. 43 处 `innerHTML =` 改走 `morph()`（拿到阶段 2 的动效、不再闪）。
3. 按页把内联样式换成阶段 1 的组件和类，顺序按内联样式多少：arena → 概览 / Agent（app.js）→ views2 → views → 设置 → hub。每页一个施工单，可以并行派给不同 Agent（阶段 1 合入之后）。

### 阶段 4 · 验收

- 护栏数字目标：内联样式 328 → ≤ 30（只留动态宽度这类必须的），写死颜色 61 → 0（tokens.css 与预设强调色除外），字号写法 102 → ≤ 8，按钮组合 61 → ≤ 8，`innerHTML =` 43 → ≤ 5。
- 现有测试全过，包括对比度（ADR 0007）与 `scripts/ui_audit.py` 的 Tab 焦点检查。
- 新增动效冒烟：morph 一个列表，断言新增条目拿到 enter、换位条目触发 FLIP、`data-state` 变化触发 state；reduced-motion 下断言全部跳过。
- 逐页截图（浅色 / 深色各一张）放进合入说明，前后对比。

## 为什么这样做

- **先组件、后动效、再搬页面**：动效挂在 `data-key` / `data-state` 这些约定上，约定没定之前搬页面等于搬两次。
- **动效在 morph 里统一接线**：这是让"动感"在全站一致、且以后的新页面自动具备的唯一办法；逐页手写动画会重演今天的样式问题。
- **护栏先行**：工作台由很多 Agent 并行改前端，没有测试守着，统一一周后就会被新代码冲散。

## 放弃了什么

- 换 React / Vue / Svelte：要重写全部约 4500 行前端（不含 vendor）和 33 个前端测试，收益（组件化）用模板函数 + 约定也能拿到。
- 换配色 / 换字体：ADR 0007 刚把对比度调到达标，没有证据表明配色是痛点。
- 动效库（GSAP / Motion One）：5 个动效用 Web Animations API + CSS 足够，不引依赖。
- 一次性大重写：分阶段才能每步可审、可回滚，并且不阻塞其他 Agent 同时改前端。

## 风险

- **morph 与动画打架**：idiomorph 复用节点时动画可能作用在错误的元素上 → 列表条目必须有稳定 `data-key`，没有 key 的列表不加 enter/exit（阶段 0 的护栏里加一项"列表条目缺 key"计数）。
- **拆 app.js 期间与其他施工冲突**：阶段 3 第 1 步要在一个短窗口内完成，窗口内暂停派发改 app.js 的施工。
- **性能**：只动 transform/opacity；实时数据每次刷新只对变化的节点触发动效，不对整页。

## 回滚

每阶段独立提交，`git revert <该阶段合入提交>`。阶段 2 另有开关：`prefs` 里关闭"界面动效"等同 reduced-motion。
