# 0026 直连 Agent

日期：2026-10-21。状态：已采纳（本人确认：外部窗口接入、仿 Codex / Claude Code 的权限模式、名字叫「直连 Agent」）。

## 问题

现有 Agent 只有两种身份：Leader 和队员。两者都围着派发—合并流程转，要一直挂着轮询待命，能读写的只有全局一个工作区。本人想要第三种：自己单独对话、单独派活，不归 Leader 管，用完即走；能碰哪些文件夹、权限多大、看得到哪些背景，都能逐个调。项目层面也没有登记「这个项目相关的本机文件夹」的地方。

## 决定

1. **接入方式**：直连 Agent 仍是外部窗口（网页版 AI、Claude Code、Claude 桌面、Codex 等）通过本机 MCP 接入，但用自己的令牌。MCP 按连接身份分工具：直连令牌只看得到、只调得动 `direct_*`；Leader / 队员看不到 `direct_*`。只藏不拦不够，`call_tool` 处同样拦。
2. **范围**：每个直连 Agent 有自己的文件夹清单（可写 / 只读）；文件工具只在清单内工作，越界、凭据文件、写只读文件夹一律拒绝。复用 `named_workspace_io` 的凭据拒读，但写入自己实现：保留原文件换行与 BOM、锁文件放在 `console/direct/locks/`，不在用户仓库里留东西。
3. **权限模式**：只读 / 逐项审批 / 自动改文件（默认）/ 完全放开。只读命令任何模式直接放行；带串联、重定向符号的命令不自动放行；推送、建 PR、发 Release、`gh api` 等外发命令除完全放开外总要批准。
4. **审批**：需要批准的操作写成记录（完整操作 + sha256），工具调用最多阻塞 45 秒等结果，超时返回 PENDING，Agent 用 `direct_approval` 取结果。本人在工作台批准 = 工作台按记录原样执行一次；记录被改过拒绝执行；执行中进程退出落 `unknown`，不自动重试；待批 24 小时作废。
5. **提示词**：`direct_info` 返回完整工作守则：身份、文件夹、模式、相关项目背景、本人写的说明、工作方式（先读后改、PENDING 怎么办、不绕审批、对外动作先在对话里确认、如实报测试结果、[已验证]/[推断]）。
6. **项目文件夹**：项目新增 `folders` 字段，可在网页上改；直连 Agent 从这里挑。施工仓库 `repo_dir` 不变，仍只能走 ADR 0020 的命令行绑定。
7. **界面**（2026-10-22 修订）：不另开页面，并进工作台主框架，跟其它 Agent 同一套交互。Agent 页分组网格第一张「直连 Agent」卡，每人一个胶囊；点开在抽屉里分「工作 / 设置 / 接入 / 活动」；新建、全部待批也是抽屉；项目文件夹在「项目配置」抽屉里改。代码在 `web/v2/js/direct-ui.js`，`main.js` 只把它的动作和表单挂进全站委托表。最初的独立页 `web/v2/direct.html` 因风格和交互跟工作台割裂被本人否掉，现只留跳转。桌面通知插件默认加上 `direct.approval_requested`。

## 取舍与边界

- 命令是宿主等权执行，不是沙箱；cwd 只是起点。诚实写在页面、工具说明和守则里，靠审批卡展示完整命令把关。
- 直连 Agent 不轮询，工作台派的任务要本人在它窗口里说一句「看看任务」才会被读到。没做工作台主动唤醒。
- 公网隧道下直连令牌能远程调用，等同于持有该 Agent 权限；令牌可一键更换、Agent 可停用，停用后立即 401。

## 验收

`tests/test_direct_agent_20261021.py`：文件夹边界、四档模式分流、批准后执行一次、篡改拒绝、拒绝不执行、CRLF 保留、PowerShell 引号与中文、真实 MCP 进程上的身份隔离与停用即失效。界面在临时实例上用浏览器验收（宽屏 / 手机宽度、草稿不被刷新冲掉、无控制台报错、Agent 页随状态立即重画）。

## 回滚

revert 本功能提交并重启工作台与 MCP。`console/direct/` 的配置、审批与活动记录是运行数据，回滚不删；项目记录里多出的 `folders` 字段旧版本会忽略（但旧版 `update_project` 会拒绝再改它）。
