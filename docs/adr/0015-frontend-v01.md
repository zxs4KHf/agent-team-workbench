# 0015 v0.1 前端：按页面拆模块，全站统一成「概览」的版式

- 状态：已接受（2026-10-02，用户：「按照概览页面的风格进行统一」「允许较大改动，甚至从架构底层重构」「不引入构建，原生模块拆页面」）
- 关联：ADR 0011（设计守卫 / 棘轮）、0014（Arena 插件化）

## 现状

- `web/v2/js/app.js` 161KB：外壳、路由、全部页面的动作、表单、抽屉、拖拽都在一个文件里；`views.js` 59KB、`views2.js` 49KB 混放多个页面。
- 只有「概览」做过一屏版式（页头 + 标签面板 + 栏内滚动 + 分页贴栏底）。「进行中 / 决策 / 成果 / 任务历史」还是一长串卡片往下排，没有分页；按钮组合、卡片密度、提示条位置各页不同。

## 决定

### 1. 统一版式（每个列表型页面都长这样）

```
页头：小标题 · 大标题 · 一句说明            右侧：本页主操作（最多 2 个按钮）
筛选条：搜索框 · 筛选片 · 计数                （可选）
面板（卡片）：标签（可选）→ 列表（栏内滚动）→ 分页条（贴面板底）
```

- 面板高度锁在窗口内（与概览同一套 `--ov-top` 量法与分档），页面本身不滚；窄屏单栏、矮屏放开。
- 列表一律分页（`capped()`），不再「显示其余 N 项」。
- 一行一个对象：标题一行、元信息一行、右侧状态与 1 个主按钮；次要操作收进「⋯」或展开区。
- 危险操作（取消、删除、清理）只用 `danger` 样式，且一定二次确认。

### 2. 组件（`web/v2/js/ui/`）

| 组件 | 用途 |
|---|---|
| `pageHead(kicker, title, desc, actions)` | 页头 |
| `panel({ tabs, group, body })` | 标签面板（由概览的 `ovTabs` 泛化），标签记在本机 |
| `capped(key, items, render, size)` | 分页列表（已有，挪进来） |
| `row({ title, meta, status, action })` | 列表行 |
| `chip / button / empty / banner` | 现有类名的唯一生成入口 |

### 3. 代码结构

```
web/v2/js/
  app.js            外壳：顶栏、导航、路由、事件委托（只认 data-action / data-form，按页面登记）
  core.js model.js components.js   不变
  ui/               上面的组件
  pages/overview.js running.js decisions.js artifacts.js compose.js agents.js settings.js history.js
                    每个文件导出 { render, actions, forms }，app.js 合并登记
```

- 不引入构建：浏览器原生 ES 模块，改完刷新即生效。
- 拆分按页面一个一个做，每拆一页：钉源码的测试改指向新文件（原意不变），设计棘轮计数只降不升。

### 4. 配色与字号

- 只用 `styles/tokens.css` 的变量；状态色固定四种：成功（ok）、提醒（warn）、出错（bad）、信息（info），紫色只给「等你拍板」。
- 字号只用 `--fs-*` 档位，不写死 px（已有守卫）。

## 验收

- 每个列表页在 1440×900、1920×1080 下页面不滚动，分页条可见；≤1100 单栏不横向溢出。
- `app.js` 只剩外壳（目标 < 40KB），页面代码都在 `pages/`。
- 设计棘轮计数不升；全量测试通过。

## 回滚

按页面分提交，`git revert` 单页即可回到旧版式。
